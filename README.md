# Molecular Graph Learning for Solubility Prediction

This project investigates graph neural networks for molecular property
prediction using the ESOL aqueous solubility dataset.

Models:
- Graph Convolutional Network (GCN)
- Graph Attention Network (GAT)
- Bond-aware GINE

Evaluation includes random splitting and Bemis-Murcko scaffold splitting.

Full documentation will be added after experiment packaging.
